# Uvolvweb

Production website folder for Uvolv.tech.

The current visual prototype remains in `../yoooaiiii`. Build the Next.js production site here, using `../AGENTS.md` and `../docs/uvolvweb-grand-plan.md` as the implementation brief.

Planned stack:

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Radix/shadcn-style accessible primitives

Do not treat this folder as a throwaway prototype. It is the production app home.
